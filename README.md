# Open Fiel Service Management

Solucion tecnologica de Codigo Abierto Capaz de Coordinar técnicos, visitas, órdenes de trabajo y servicios en campo.
con arquitectura Multi-tenacy,Serverless y basada en eventos
## Estructura 

Backend    : Codigo y funciones serverles por microservicio dedicado
Fronted    : Apariencia web del Cliente 
DataIngest : Script en python para Generar data Sintetica
